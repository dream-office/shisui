# 隐私边界（v1.3）

## 默认

- 无账号、无服务器、无上传；待办数据只存浏览器 IndexedDB。
- 文档（PDF/DOCX/TXT/MD）**只在本机解析**，文件与提取文本不离开浏览器。
- 本地 OCR（Tesseract.js）**只在本机运行**；语言包/ wasm / worker 从本站加载，不上传图片或识别结果。

## 会出网的两种情况（都由用户主动触发）

1. **AI 解析文本**：在设置页配置 API 后，点「开始解析」时通知文本会发送到你配置的服务。
2. **AI 识图**：已配置 API，且每次上传前勾选「我确认发送这张图片」；压缩后的图片会发送到你配置的服务。

## 不会做的事

- 不会自动上传图片、文档或 OCR 结果；未确认=0 请求。
- 不会把 base64、图片或文件名写进日志、任务 rawText、备份或公开仓库。
- 不会把语言包/ worker 指向 CDN（构建产物校验无外部 URL）。
