# 统计口径说明（v1.6）

> 全部在本地计算，不上传；数据只来自本机 IndexedDB 与 localStorage 的专注日志。

## 指标

- **本周完成率**：分母 = 开始/截止时间（`startAt ?? dueAt`）落在本周的任务；分子 = 其中 `done=true`。以周一为一周起点。**跳过的任务不计入分母**。
- **解析手改率**：分母 = `engine` 为 rule / llm / hybrid 的任务（跳过不计）；分子 = `editedFields` 非空的数量；手动添加 / 日历导入不算。
- **延期完成率**：分母 = 已完成且带实际完成时间 `doneAt` 的任务；分子 = `doneAt` 晚于 `dueAt ?? startAt` 的数量。历史完成但无 `doneAt` 的旧数据不计入分母（没有完成时间，无法判断）。
- **8 周完成趋势**：含本周在内最近 8 个自然周（周一 00:00 起）；每周按到期/开始时间归属，跳过不计；无任务的周显示「—」。
- **按任务类型分布**：全部任务（含已完成/跳过）按 `kind` 计数，按数量降序。
- **每日专注趋势**：最近 7 个自然日；专注段跨零点只算当天部分；统计页显示分钟数。
- **未完成 / 全部**：`open = !done && !skipped`；`skipped` 单独显示。
- **逾期分桶 / 冲突体检**：只看 `!done && !skipped`；逾期按 `dueAt ?? startAt` 与当前时间差分成 <1 天 / 1–3 天 / 3–7 天 / >7 天。

## 专注计时规则

- 只记录完整结束、时长 ≥1 分钟且 ≤4 小时的专注段；最近保留 120 条。
- 切走标签页/锁屏：**30 秒内回来**继续同一段计时；超过 30 秒才结算当前段。
- 关闭/刷新（pagehide）立即结算；进行中的计时只存当前标签页 sessionStorage。

## 导出

- **CSV**：摘要 + 8 周趋势 + 类型分布 + 7 天专注；UTF-8 BOM，Excel 可直接打开。
- **PNG**：1200×1600 画布（2x 缩放），包含摘要、趋势、类型、专注，不依赖图表库。
